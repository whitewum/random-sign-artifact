# Manuscript

`main.pdf` is the compiled preprint (version 0.1, 2026-10-27). To rebuild it, generate the figures first (`make figures` at the repository root, which writes PDFs to `../figure/`), then run `./build.sh` here; it requires `latexmk` and `pdflatex`.
