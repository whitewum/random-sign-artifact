\section{Exact evaluation and search cutoffs}\label{app:search}
We describe how to compute the Skellam rule (Definition~\ref{def:skellam}). We derive an exact expression for $G_n(\widetilde d)$, state and prove two search cutoffs, and explain the numerical implementation of the exact CDF.

The Skellam rule's guarantee holds for arbitrary acceptance sets. As defined, the implementation returns the largest accepted candidate. The candidate range is unbounded, so we need an explicit cutoff. Proposition~\ref{prop:cut11} gives a cutoff of about $1.035$ times the observation $\widetilde d$ at $M=16384$ and $u=0.01$. We search downward from the cutoff and return the first accepted candidate, obtaining the same result as an unbounded scan. Both the number of candidates requiring an exact CDF and the Poisson window length are proportional to $c$. The cost of a single sizing is therefore roughly proportional to $\lambda_d$. The Poisson table depends only on $(M,k)$ and the candidate $n$, so the same receiver can reuse it across syncs. Appendix~\ref{app:timing} reports measured results.

\subsection{\texorpdfstring{Computing $G_n(\widetilde d)$ with integer thresholds}{Computing G_n with integer thresholds}}
Expanding \eqref{eq:aux} over the two cases $\varepsilon_1\varepsilon_2=\pm1$, we obtain
\begin{equation*}
G_n(\widetilde d)=\frac12\Pr\Bigl(Z_n\le\frac k2\bigl(\widetilde d-n-2\bigr)\Bigr)+\frac12\Pr\Bigl(Z_n\le\frac k2\bigl(\widetilde d-n+2\bigr)\Bigr).
\end{equation*}
Let $R=\sum_vC_v^2$, an integer, so that $\widetilde d=R/k$. A random variable with CDF $G_n$ is at most the observation if and only if $Z_n\le\frac k2(R/k-n\mp2)$, or equivalently $Z_n\le\lfloor(R-kn\mp2k)/2\rfloor$. Thus $G_n(\widetilde d)$ equals
\begin{equation*}
\frac12\Pr\Bigl(Z_n\le\Bigl\lfloor\frac{R-kn-2k}2\Bigr\rfloor\Bigr)+\frac12\Pr\Bigl(Z_n\le\Bigl\lfloor\frac{R-kn+2k}2\Bigr\rfloor\Bigr),
\end{equation*}
where we compute both floors using integer arithmetic. This preserves decisions at lattice boundaries in floating-point computations.

\subsection{Search cutoff from the Chernoff bound}
\begin{proposition}[Chernoff cutoff]\label{prop:cut10}
If $e^{-9M/80}<u$, then every candidate satisfying
\begin{equation}
n\ge\max\Bigl\{4\Bigl(\widetilde d+2\Bigr),\ \frac M{2k},\ 4\Bigr\}\label{eq:cut10}
\end{equation}
is rejected. If $e^{-9M/80}\ge u$, the rule immediately returns $+\infty$.
\end{proposition}

At $M=64$, we have $e^{-9M/80}\approx7.5\times10^{-4}$, so the condition holds for both $u=0.01$ and $0.05$. For any fixed $u$, the branch returning $+\infty$ disappears as $M\to\infty$, leaving Theorem~\ref{thm:coverage} unchanged.

\begin{proof}
The component with shift $-2$ bounds the lower tail of the null distribution. It therefore suffices to prove $\Pr(n-2+\frac2kZ_n\le R/k)\le e^{-9M/80}$ under \eqref{eq:cut10}. Since $n\ge4(R/k+2)$, we have $R/k-n+2\le-\frac34n$, so the event requires $Z_n\le-\frac{3k}{8}n$. The two Poisson parameters of $Z_n$ sum to $2\lambda_n\le k^2n^2/(2M)$. The Skellam moment generating function is $\E e^{-tZ_n}=\exp\{2\lambda_n(\cosh t-1)\}$. The exponential Markov inequality (Chernoff bound) then gives, for $t>0$,
\begin{equation*}
\Pr\Bigl(Z_n\le-\frac{3kn}8\Bigr)\le\exp\Bigl\{-\frac{3kn}8t+2\lambda_n(\cosh t-1)\Bigr\}.
\end{equation*}
Take $t=M/(2kn)$. Since $n\ge M/(2k)$, we have $t\le1$. We use $\cosh t-1\le\frac35t^2$ for $0\le t\le1$, which follows by comparing the power series term by term with $t^2$ and using $\cosh1-1<3/5$. The exponent is at most $-\frac{3M}{16}+\frac{k^2n^2}{2M}\cdot\frac35\cdot\frac{M^2}{4k^2n^2}=-\frac{3M}{16}+\frac{3M}{40}=-\frac{9M}{80}$. The condition $n\ge4$ ensures that the expression for $\lambda_n$ is valid.
\end{proof}

\subsection{Smaller cutoff from the Bernstein bound}
The coefficient $4$ in Proposition~\ref{prop:cut10} gives a scan range of about $3U$ candidates. The Bernstein bound for the Skellam distribution yields a smaller cutoff.

\begin{proposition}[Bernstein cutoff]\label{prop:cut11}
If $M>4\log(1/u)$, then every candidate satisfying
\begin{equation}
n\ge\frac{\widetilde d+2+\frac{4}{3k}\log(1/u)}{1-2\sqrt{\log(1/u)/M}}\label{eq:cut11}
\end{equation}
is rejected.
\end{proposition}

At $M=16384$ and $u=0.01$, the coefficient of the observation $\widetilde d$ in \eqref{eq:cut11} is about $1.035$. This reduces the scan from about $3U$ candidates to one or two hundred, with the same number of candidates requiring an exact CDF. We search downward one candidate at a time, starting one below the smaller of the two cutoffs.

\begin{proof}
For $0<t<3$, we have $\log\E e^{-tZ_n}=2\lambda_n(\cosh t-1)=2\lambda_n\sum_{j\ge1}t^{2j}/(2j)!\le\lambda_nt^2\sum_{j\ge0}(t/3)^{j}=\lambda_nt^2/(1-t/3)$, since $2/(2j)!\le3^{-(2j-2)}$. Thus $-Z_n$ is a sub-gamma variable with variance factor $2\lambda_n$ and scale $1/3$. The standard Bernstein argument \cite{boucheron2013concentration} gives
\begin{equation*}
\Pr(Z_n\le-x)\le\exp\Bigl[-\frac{x^2}{4\lambda_n+2x/3}\Bigr],\qquad x>0.
\end{equation*}
A sufficient condition for the right-hand side to be at most $u$ is $x\ge2\sqrt{\lambda_n\log(1/u)}+\frac23\log(1/u)$. Taking $x=\frac k2(n-R/k-2)$ and using $\lambda_n\le k^2n^2/(4M)$, we obtain the sufficient condition $\frac k2(n-R/k-2)\ge kn\sqrt{\log(1/u)/M}+\frac23\log(1/u)$. Rearranging gives \eqref{eq:cut11}, whose denominator is positive because $M>4\log(1/u)$. For $\lambda_n=0$, the lower tail is zero, so the conclusion follows directly.
\end{proof}

In the implementation, we compute the cutoff at risk $u(1-10^{-9})$, round up, and add one. For the experimental values $u=0.01,0.05$, this risk is below the acceptance level $u-10^{-12}$. These adjustments move the cutoff toward larger candidates. The scan starts one below the cutoff and proceeds downward, avoiding a cutoff that is too small and would skip a candidate that should be accepted.

\subsection{Per-candidate Chernoff prescreening}
For each candidate with $j=\lfloor(R-kn+2k)/2\rfloor<0$, we first compute a Chernoff bound for the Skellam lower tail. We evaluate the exponential Markov bound from the moment generating function above at the optimal parameter $t=\operatorname{asinh}r$, where $r=-j/(2\lambda_n)$:
\begin{equation*}
\Pr(Z_n\le j)\le\exp\Bigl\{-\Bigl[(-j)\operatorname{asinh}r-2\lambda_n\bigl(\sqrt{1+r^2}-1\bigr)\Bigr]\Bigr\}.
\end{equation*}
The component with shift $-2$ has the larger CDF. If its Chernoff bound is at most $u(1-10^{-9})$, the average is at most $u$, and we reject the candidate immediately. Prescreening rejects only candidates certified for rejection by this bound. Computing exact CDFs for every candidate with prescreening disabled gives the same result for every case.

\subsection{Windowed Poisson table for the exact CDF}
We use $\Pr(Z_n\le j)=\sum_m\Pr(P_2=m)\Pr(P_1\le j+m)$, where $P_1,P_2$ are independent $\Pois(\lambda_n)$ variables. For each candidate, we build a Poisson table restricted to the window $[\lambda_n-w,\lambda_n+w]$, with $w=14\sqrt{\lambda_n}+40$. Starting at the mode, we compute the pmf recursively in both directions using $p(i+1)=p(i)\lambda_n/(i+1)$, normalize within the window, and accumulate the CDF. The Poisson tail Chernoff bound places the mass beyond each end of the window below $10^{-40}$, smaller than double-precision rounding error. Normalization also avoids the relative error from evaluating $\log\Gamma$ term by term at large $\lambda_n$. The initial implementation builds the table from zero to $\lambda_n+14\sqrt{\lambda_n}$. At $M_1=16384$ and load $3$, $\lambda_n$ ranges from about $2\times10^5$ to $4\times10^5$. A single sizing takes about $1.3$ s, and the statistical experiments exhaust memory. With windowing, a single sizing takes about $36$ ms and produces the same result for every case.

The Poisson table depends only on $(M,k)$ and $n$, so we can share it across syncs and risk levels. We maintain a cache keyed by $(M,k)$. When full, it evicts the least recently used tables until half its capacity is free. We measure capacity in entries, each containing two float64 values.

The cutoffs, prescreening, and windowed tables preserve the rule's output. We verify this case by case against a reference implementation with 70 decimal digits of precision (4536 general cases and 286 bounded-$c$ cases, covering lattice points, parity boundaries, and $+\infty$). We also compare the windowed implementation with cutoffs against the full-table implementation on 9779 cases. The results agree in every case.
