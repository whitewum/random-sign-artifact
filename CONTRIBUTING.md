# Contributing

Please open an issue describing the scientific or implementation problem and provide the command, seed, configuration, tool versions, and observed result. Submit focused pull requests with a description of any changed statistical assumptions or output schemas.

Run `make test`, `make smoke`, and `make audit` before submitting. Run `make figures` when changing analysis or plotting code. Preserve frozen configurations and historical data; add a versioned dataset for new experiments. Update the provenance and integrity manifests when intentionally changing tracked files. Keep all source comments, documentation, and user-facing messages in English. Contributions are licensed under MIT.
